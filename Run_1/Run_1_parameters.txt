1. Dataset & Preprocessing
Data Source: 10,000 samples extracted from NLC_OFF_IQdata_Receiver.xls and NLC_ON_IQdata_Receiver.xls
Normalization: Standard Scaling (Zero-mean, Unit-variance) applied across both I and Q channels.
Sequence Windowing:
WINDOW = 256
STRIDE = 128
Train/Validation Split: 80/20 (Clean split performed before windowing to prevent data leakage)


2. Model Architecture (Transformer Encoder)
d_model = 64 (Embedding dimension)
nhead = 4 (Number of attention heads)
num_layers = 2 (Number of Transformer encoder layers)
dim_feedforward = 128 (Hidden size of the feedforward network)
dropout = 0.1
Positional Encoding: Explicit sine/cosine positional encoding added to the input embeddings.


3. Loss Function & Weights
The model learned the residual Δ_hat using a combined domain-aware loss:

IQ Correction MSE (Base loss)
Amplitude Preservation MSE: Weight = 0.5
QPSK Snapping Loss (L2 distance to closest ideal symbol): Weight = 0.05
DC-Centering Loss (Penalize I/Q centroid displacement): Weight = 0.1'

4. Training Hyperparameters
Optimizer: AdamW
Learning Rate: 3e-4
Weight Decay: 1e-4
LR Scheduler: CosineAnnealingLR (T_max = 100)
Batch Size: 32
Max Epochs: 100
Early Stopping Patience: 15 epochs (tracking Validation Loss)
